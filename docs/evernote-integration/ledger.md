# Evernoteノウハウ統合 台帳

記入日: 2026-07-26（Phase 1）。列と判定規則の正本は `plan.md` にある。以下は記入時の参照用の要約である。

判定の4区分。迷ったら `保留・除外` に倒す。

- `既存文書に含まれる` … 企画、構成、タイトル、記事広告、SEO。キャリア・働き方、学習・健康・お金も原則ここか `保留・除外`
- `既存文書へ追記` … 取材・インタビューの手順（対応先は企画構成プレイブックの新章）
- `新規文書へ採用` … 対応先は次の3文書に限る
  - メディア設計・運営プレイブック（KPI、体制、ポジショニング、収益モデル。企画制作と重なる部分は採用しない）
  - 営業・提案・クライアントワークプレイブック（ヒアリング、提案、修正、検収、レポート）
  - 編集者育成・制作組織プレイブック（研修、編集長育成、役割設計、採用）
- `保留・除外` … 新規事業・起業の方法論（将来の独立候補として理由欄に明記）、Webクリップ・メールマガジン・書籍の抜き書きなど本人の実務ノウハウでないもの、要OCRのノート
